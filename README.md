# Yahya Dental Clinic

A compact dental clinic landing page built with Next.js App Router, TypeScript, Tailwind CSS v4, and Motion.

## Clinic information

- Address: Fatima Tower, Main Road, Samanabad, Faisalabad, 38000
- Phone: +92 323 7004226
- Email: yahya.dental.clinic@gmail.com
- Hours: Monday–Saturday, 6:30 PM–10:00 PM (some listings show 5:00 PM–9:30 PM; call to confirm)
- Sunday: Closed
- Google reviews: 2

Services represented in the website:

- Examination and x-ray evaluation
- Treatment planning
- Pain management and medication
- Oral care education
- Extractions, including impacted and grossly carious teeth
- Tooth-colored fillings
- Root Canal Treatment (RCT)
- Crowns and bridges
- Partial and complete dentures
- Scaling and polishing
- Teeth whitening
- Braces and aligners

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```sh
npm run build
```

The project uses a static export and can be served from `out/` after a successful build.

## Content and assets

Clinic identity and contact links are centralized in `lib/clinic.ts`. The visual assets are illustrative dental-care imagery and do not represent actual patients or clinical results.
